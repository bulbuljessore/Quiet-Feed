# Ready-to-use folders / তৈরি ফোল্ডার

Two folders, one for each kind of browser. Pick the one for your browser and load **that folder** (nothing else in this repository is installable).

দুটো ফোল্ডার, দুই ধরনের browser-এর জন্য। আপনার browser-এর ফোল্ডারটাই লোড করুন (রিপোর আর কিছু সরাসরি ইনস্টল করার জন্য নয়)।

| Folder | For | Load it with |
|---|---|---|
| [`chromium/`](chromium) | **Chrome, Edge, Brave, Opera, Vivaldi, Arc** | `chrome://extensions` → Developer mode → **Load unpacked** → choose this folder |
| [`firefox/`](firefox) | **Firefox** | `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on...** → choose `firefox/manifest.json` |

The same two packages are also available as ZIP files on the [Releases](../../../releases/latest) page (`quiet-feed-chromium.zip`, `quiet-feed-firefox.zip`).
এই দুটোই [Releases](../../../releases/latest) পেজে ZIP আকারেও আছে।

These folders are generated by `node build.js`. Do not edit them by hand.
